WINDOWS

Minimum
OS: Windows 10 or 11, 64-bit
Processor: any dual-core processor from the last ten years
Memory: 2 GB RAM
Graphics: any graphics card or integrated graphics supporting OpenGL 3.3
Storage: 100 MB available space

Recommended
Memory: 4 GB RAM
Additional notes: The game is 2D and about 55 MB. The desktop strip needs a desktop with window transparency, which Windows 10 and 11 have.


MACOS

Minimum
OS: macOS 13 Ventura or later on Apple silicon, macOS 11 Big Sur or later on Intel
Processor: Apple silicon or a 64-bit Intel processor
Memory: 2 GB RAM
Graphics: any Mac that runs these versions of macOS
Storage: 250 MB available space

Recommended
Memory: 4 GB RAM
Additional notes: The game is 2D and runs natively on Apple silicon and Intel Macs.


LINUX / STEAMOS

Minimum
OS: a 64-bit distribution from the last five years, or SteamOS
Processor: any dual-core processor from the last ten years
Memory: 2 GB RAM
Graphics: any graphics card or integrated graphics supporting OpenGL 3.3
Storage: 150 MB available space

Recommended
Memory: 4 GB RAM
Additional notes: The game is 2D and about 100 MB. The desktop strip needs a desktop with window transparency (a compositing window manager).
